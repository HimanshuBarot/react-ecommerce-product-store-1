# React E-commerce Product Store 🛍️

A responsive and modern frontend e-commerce web app built with **React** and **Bootstrap**. This application fetches product data from a third-party API and displays it in a clean, user-friendly interface.

## 🚀 Features

- 📦 Fetches products dynamically using API
- 🖼️ Displays product images, names, prices, and details
- 💡 Responsive UI with Bootstrap & Bootstrap Icons
- 🔄 Dynamic routing using React Router
- 🧩 Modular React components structure

## 🛠️ Tech Stack

- **Frontend**: React JS, HTML5, CSS3, JavaScript
- **Styling**: Bootstrap 5, Bootstrap Icons
- **Routing**: React Router DOM
- **API**: Product list fetched from external API (like DummyJson)
